# SUBTYPE 자유주행 — 공항·터미널역 이동 (2차)

## 플레이 방법

1. 자유주행에서 실제 공항 접근 철도역에 도착하여 역명을 입력한다.
2. **✈ 공항 이동**을 누르고 목적지 공항을 선택한다.
3. 복수의 터미널 철도역이 있는 공항은 **도착 터미널·철도역**을 고른다.
4. 목적지 공항의 이름 또는 IATA 코드를 입력해 가상 항공 이동을 시작한다.
5. 선택한 터미널 철도역이 실제 게임의 철도 노선에 등록되어 있어야 그 역에서 자유주행을 재개한다. 해당 역의 노선 데이터가 없으면 이동은 취소되고 기존 역으로 복구된다.

**표는 지원할 역 이름의 카탈로그이며 모든 목적지의 실제 게임 데이터 확보·도착 성공을 보증하지 않습니다.** 출발/도착역은 현재 공개된 SUBTYPE 데이터의 역명·국가·위치·운행 노선과 대조합니다. 노선이 미구현 또는 미공개이면 공항 코드를 입력해도 이동은 실패합니다. 버스 정류장이나 미검증 가상 역은 사용하지 않습니다.

**철도역과 터미널을 혼동하지 않습니다.** 나리타 제3터미널은 독립 철도역이 없으므로 '제2·3터미널 공용역'으로만 등록했습니다. 히스로 제2·3터미널도 하나의 공용역입니다. 샤를드골공항 1역은 터미널 1과 동일 건물에 있는 역이 아니며 CDGVAL로 접근합니다. 공항 간 비행은 **게임 내 가상 이동**이며 실제 항공편·운항 여부·시간표·요금·보안구역 출입 권한을 의미하지 않습니다.

## 구현

- `js/airport-free-drive.js`: 국가·위치·역명 별칭 매칭, 터미널별 목적지 UI, 기록 저장
- `js/app.js` / `js/app.bundle.js`: 선택한 터미널의 역만 검색하고 해당 자유주행 네트워크에서 재시작; 실패 시 역·국가·방문 기록 복구
- `css/airport-free-drive.css`: 터미널 선택 UI
- `tools/test-airport-free-drive.cjs`: 터미널 독립성, 지역·국가 간 오검출, 배포 자산 검증

## 커스텀 노선 제작기의 공항 환승 (v0.13.1)

- `CUSTOM`에서 철도로 실제 공항 접근역에 도착하면 **✈ 공항 환승** 패널이 나타납니다.
- 현재 선택한 **국가 안에서** 데이터가 확보된 도착 공항/터미널 철도역만 선택할 수 있습니다. 목적지 역을 추가한 뒤 철도 최단거리 연결을 계속할 수 있습니다.
- 공항 간 이동은 **게임 내 가상 항공 구간**이며 실제 항공편이나 철도 선로가 아닙니다. 같은 공항의 서로 다른 터미널역 연결은 **가상 터미널 이동**으로 표시합니다. 실제 터미널 셔틀·운임·환승 허용 여부를 의미하지 않습니다.
- 최단 철도 경로를 찾을 때 가상 항공 구간은 자동으로 사용하지 않으며, 이용자가 공항역에서 명시적으로 선택할 때만 저장합니다. 지도·노선도에는 일반 철도와 다른 점선으로 표시합니다.
- 현재 커스텀 노선은 국가별 철도 데이터만 불러오므로, **서로 다른 국가 간 항공 이동은 자유주행 공항 이동 기능**을 이용해야 합니다. 홍콩의 엄격한 커스텀 선로 검증 시스템에서는 가상 공항 이동을 허용하지 않습니다.
