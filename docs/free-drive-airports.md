# SUBTYPE 자유주행 — 공항 간 이동 (1차)

## 플레이 방법

1. 자유주행에서 공항과 연결된 철도역으로 이동하고 역명을 입력한다.
2. 우측 상단 **✈ 공항 이동**을 눌러 목적지 공항을 선택한다.
3. 도착 공항의 한국어 이름 또는 IATA 코드를 입력한 뒤 **항공 이동 시작**을 누른다.
4. 연결 가능한 공항 철도역이 있으면 해당 국가의 철도 데이터를 읽고, 그 역에서 새로운 자유주행을 시작한다.
5. 기존 인접역 타이핑·노선 선택·환승을 계속 이용한다.

## 1차 등록 공항

| 코드 | 공항 | SUBTYPE 국가 |
| --- | --- | --- |
| ICN | 인천국제공항 | kr |
| GMP | 김포국제공항 | kr |
| NRT | 나리타 국제공항 | jp |
| HND | 하네다 국제공항 | jp |
| KIX | 간사이 국제공항 | jp |
| HKG | 홍콩 국제공항 | hk |
| TPE | 타오위안 국제공항 | tw |

**주의:** 공항 간 이동은 게임 내 가상 항공 연결이다. 실제 직항편, 항공 시간표, 항공권 가격이나 운항 여부를 의미하지 않는다. 공항 위치는 역 매칭용 참고 좌표이며 철도 선로망에 추가되지 않는다.

## 구현 구성

- js/airport-free-drive.js — 공항 코드·역명 별칭·위치 검증, 공항 이동 창, 이름/IATA 입력, 로컬 항공 이동 기록 50건
- js/app.js — 도착 국가 로딩, 공항역 선택·자유주행 재시작, 이동 실패 시 이전 국가·역·방문 목록 복구
- css/airport-free-drive.css — 모바일/PC 및 라이트/다크 대응
- js/app.bundle.js — 배포용 기존 게임 번들에도 동일한 app.js 변경 반영
- tools/test-airport-free-drive.cjs — 공항별 매칭·국가 격리·좌표 오검출·배포 연결 회귀 검사

공항 이동은 기존 FreeDrive 철도 그래프에 항공편을 선로 edge로 추가하지 않는다. 따라서 철도역 건너뛰기나 존재하지 않는 선로를 만들지 않는다.

## 한계와 안전장치

- 이름과 좌표를 함께 확인한다. 좌표가 없는 홍콩의 일반적인 '공항' 역명은 공항철도 노선 문맥까지 확인한다.
- 공개 카탈로그에서 해당 공항역을 찾을 수 없거나 도착역 데이터 로딩이 실패하면 비행 이동을 완료 처리하지 않는다.
- 탐색할 지연 로딩 노선은 최대 24개 후보로 제한한다.
- 항공 이동 기록은 해당 브라우저의 로컬 저장소에만 보관하고, Supabase 공개 랭킹에 등록하지 않는다.
- 항공 이동 경로 지도·실시간 비행·항공 시간표·터미널 내 이동은 1차 범위에서 제외한다.

## 검증

실행 명령: node --test tools/test-airport-free-drive.cjs

공항 매칭·정적 연결 검사와 실제 브라우저의 국가 전환·완주 검사는 구분한다. 7개 공항 전체를 실제 배포 브라우저에서 종단 간 주행하는 검증은 별도로 필요하다.
