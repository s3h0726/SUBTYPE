카탈로그별 단위가 다르다. 홍콩은 방향별 서비스 레코드를 세며, 한국은 하나의 노선에 여러 방향과 패턴을 담는다. 대만은 내부 선로 두 건을 포함하고, 일본은 앱이 생성하는 특급 카드와 별도로 로드하는 디즈니 리조트라인을 포함한다. 사용자 제작·연구 전용 카탈로그는 공개 등록 수에 포함하지 않았다.

기존 ID와 정차열을 재현하려면 기준 커밋에서 새 `tools/timetable-inventory.mjs`를 실행하되 `evidence.json`은 빈 객체를 사용한다. 현 작업본에서는 `node --max-old-space-size=6000 tools/timetable-inventory.mjs`가 최종 CSV와 합계를 만든다. 일본과 홍콩의 일부 노선은 이 검사에서 대표 방향을 사용하며, 실제 UI 검사는 [VALIDATION_RESULTS.md](VALIDATION_RESULTS.md)에 따로 기록했다.

공식 원본은 [SOURCE_REFERENCES.md](SOURCE_REFERENCES.md), 노선별 확인 범위는 [ROUTE_TIMETABLE_AUDIT.csv](ROUTE_TIMETABLE_AUDIT.csv)에 있다.
