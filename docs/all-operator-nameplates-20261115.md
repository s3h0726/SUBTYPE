# SUBTYPE 전 운영사 역명판 공통형 구분 확대 (2026-11-15)

## 적용 대상과 방식

- 일본의 현재 등록 목록: **160개 운영사, 610개 노선 카드** (`js/japan-lite-index.js` 기준).
- 기존 일본 역명판 지원 방식은 유지한다. 사진 자료로 구성된 역명판,
  도쿄메트로·JR·민영철도 전용 CSS, 니시테츠 전용 디자인은 건드리지 않는다.
- 전용 원본 디자인이 없는 일본 운영사는 기존 공통형 `operator-*`,
  `local`, `tram`, `monorail` 레이아웃을 유지하며, 운영사 ID를 기준으로
  **5가지 바탕 × 5가지 외곽 × 8가지 노선색 가로선**을 배정한다.
- 현재 일본 운영사 전체에 서로 다른 조합을 배정할 수 있는 **200개 조합**
  (5×5×8)을 준비했다. 실제 운영사별 CSS 변경 대상은 기존 전용 역명판을
  사용하지 않는 운영사에 한정된다.
- 한국·홍콩·대만·태국·영국·프랑스 등의 공통형 역명판에는 운영사별
  컬러 에지를 추가했다. 기존 국가별 전용 역명판은 유지한다.
- 운영사별로 실제 공식 간판 이미지/규격을 확보한 것이 아니므로 새 스타일은
  **SUBTYPE 창작 디자인**이다. 실제 역명판을 재현했다고 주장하지 않는다.

## 연결 방식

- `js/operator-nameplate-identity.js`는 현재 선택된 운영사 ID, 역명판 유형,
  현재 국가를 감지하여 전용형/공통형 여부를 판정한다.
- 기존 `Game.applyActiveBrand`가 역 도착 때 갱신하는 `data-operator-id`를
  사용하므로 직통운전 중 운영사 변경과 자유주행도 감지한다.
- 현재 노선 색상 `--route-color`를 강조선에 계속 사용한다.
- 신규 CSS와 JS는 `index.html`에 연결하며, 기존 생성 파일
  `js/app.bundle.js`는 건드리지 않는다. 다음 번 앱 번들 생성 시에도
  신규 레이어는 독립적으로 유지된다.
- `#typing-input`, `#ko-progress`, 정답·역 순서·지도·저장소를 수정하지 않는다.
  사진 역명판, 니시테츠 등은 데이터 속성을 지워 완전히 제외한다.

## 검증

```bash
npm run test:all-nameplates
```

검사: 현재 일본 운영사 전체의 고유 디자인 조합, 사진 및 전용역명판 보호,
국가 변경 때 CSS 변수 정리, 노선색 가로선 유지, 스크립트·스타일시트
로드 순서, 입력창 불간섭.

**추가 검증 필요:** 실제 배포사이트에서 각 운영사별 화면을 육안으로 확인하고,
모바일 너비·한글 조합형 입력·강조선 겹침·자유주행 및 직통운전 변경을
브라우저로 확인해야 한다. 정적 회귀 테스트만으로 위 검증을 대신할 수 없다.

## 향후 실물 역명판 기반 확대

실제 운영사별 사진/공식 디자인을 확보하는 대로
전용 CSS를 추가하고 공통형 배정을 해제한다. 공식 로고나 운영사 색상은
출처·사용 권한 검증 없이 추측하여 만들지 않는다.
