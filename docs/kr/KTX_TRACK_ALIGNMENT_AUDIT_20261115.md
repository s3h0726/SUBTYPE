## 자동 수선 실패 안전성 검사

수서~평택지제 양방향 우회 10개 운행계통을 원본 OSM 선로 노드와 인접 역간 선로의 정확한 공통 접속점 조건으로 시험했다. 10건 모두 수선 조건 불충족으로 차단됐으며 **정규 선형과 배포 데이터는 변경되지 않았다.**

- 7건: 기존 인접 구간과 신규 선로 사이 정확한 OSM 노드 접속점 미확보
- 3건: 접속 후보는 존재하나 고속선 비율과 거리 등 대체 경로 안전조건 불충족
- 두 선로가 지도상 가깝다는 이유만으로 임의의 직선이나 연결 선로를 생성하지 않음
- 수정 가능성이 검증되지 않으면 `--write` 옵션에서도 실패 종료하여 데이터 변경 거부

## 재현

```sh
node --test tools/test-kr-ktx-track-alignment.cjs
node tools/audit-kr-ktx-track-alignment.cjs
node tools/diagnose-kr-ktx-corridors.cjs
node tools/repair-kr-ktx-suseo-pyeongtaek.cjs
```

검사 결과는 reports/kr-ktx-track-alignment.json 및 reports/kr-ktx-suseo-correction.json, GitHub Actions 실행 artifact에 저장된다.

## 남은 수정 사항

1. 수서·평택지제역의 실제 연결 노드 및 분기기 조사 (승강장·인입 선로 포함)
2. 대전~동대구, 경부고속선 남부의 누락된 OSM 고속선 연결 및 공식 선로 검증
3. 구포·수원·서대전 등 기존선 경유의 합법적 우회 패턴 분류 유지
4. source-backed 연속 선형 확보 후 정규 데이터와 게임 배포 데이터 변경, 전계통 완주 시험

이 변경은 전체 선형 검사 및 안전한 자동 수정 검증 절차 추가이며, 공개 KTX 노선의 실제 수정 완료를 의미하지 않는다.
