# 수도권 전철 1호선 실제 운행계통명·공식 검증 상태 (2026-10-24)

## 적용
SUBTYPE의 정식 한국 노선 선택 화면에 통합되어 있는 수도권 전철 1호선 23개 OSM 방향별 경로에 대해, `연구용 경로`라는 플레이 표시 이름 대신 운행 종류/행선지 이름을 부여한다.

- **경인선 급행**: OSM 계통 표제에 급행이 명시된 방향 (6개)
- **경부선 일반**: 천안 시·종착 일반 경로 (3개)
- **서동탄 지선 일반**: 서동탄 시·종착 일반 경로 (7개)
- **1호선 일반**: 나머지 일반 경로 (7개)
- 계통을 고른 다음 **원래 OSM 정차 방향과 출발역/행선지**를 고르도록 묶는다.
- 게임 화면의 서비스 이름도 해당 표시 이름을 사용한다. 실제 역 배열과 선로 geometry/ID는 바꾸지 않는다.

## 운영기관 근거
- 한국철도공사, 보도자료 **「코레일, 26일부터 수도권전철 경인선 급행 운행 조정」**, 2026-05-20.
- 코레일은 2026-05-26부터 **용산~동인천 특급열차를 급행열차로 전환**한다고 공지하였다.
- OSM relation **8820537, 8820538**의 출발/종착/운행형태는 해당 공식 확인 내용과 일치하여 `operator-service-confirmed`로 표기한다. 이는 *해당 급행 운행 유형의 존재 확인*이지, 전 정차역/정확한 시간표/운행일의 최종 승인까지 완료했다는 뜻이 아니다.
- 과거 특급 relation **13695367, 13695368**은 계속 제외한다.

## 국가망 정식 승인과의 차이
- 나머지 21개 OSM 계통은 실제 이름/운행 형태로 분류했지만, 개별 운행일·정차 순서·시간표를 운행기관 자료와 대조하여 최종 승인하지 않았다.
- 따라서 소스의 `releaseStatus=research`, `playStatus=RESEARCH_PLAYABLE`, 검증 등급 및 연구 기록 분리는 **변경하지 않는다**.
- 공식 한국 노선 *선택 화면*에 들어간 상태와 운영기관이 각 세부 계통을 공식적으로 승인한 상태를 혼동하지 않는다.
- 전국 `OFFICIAL RELEASED SERVICES`는 여전히 **0개**이다. 이 파일을 근거로 임의 승격해서는 안 된다.

## 후속 공식 승격 조건
1. 각 계통의 현재 실제 운행 여부와 적용 운행일을 운영기관 시간표로 대조
2. 완행/급행의 정차역 목록, 방향 및 모든 분기 승강장 검증
3. 실제 선로 geometry / OSM 관계 대조
4. 전구간 PC·모바일 완주 및 역명 입력/IME 회귀
5. 증빙과 감사 결과 작성 후 정식 승인 단계의 별도 상태 변경

원본 preview 후보 95개, 레거시 1호선 소스 5개, 다른 지역의 1호선, 일본·홍콩 데이터는 변경하지 않는다.
