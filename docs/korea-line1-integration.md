# 한국 1호선 연구용 운행계통 통합 (2026-10-24)

## 목적과 상태

기존 한국 카탈로그의 1호선 5개 분할 노선 카드 대신 **수도권 전철 1호선** 카드 하나에서 OSM 연구용 운행계통을 선택한다. 원본 5개 JSON과 95개 연구용 미리보기 원본은 삭제하지 않는다. 소스 오류나 미리보기 로딩 실패 시 기존 1호선 구간을 유지하는 안전한 대체 경로가 있다.

- 수도권 1호선 연구용 source relation 후보: **25개**
- 이번 통합에서 선택 가능한 연구용 방향: **23개**
- 제외: 13695367, 13695368 (2026년 5월 폐지된 동인천 특급, 현재 여객운행으로 승인 불가)
- 다른 도시의 1호선(부산·대전·광주·인천): **통합 대상 아님**
- 정식 공개/시간표 검증·전국 공식 release: **0개** (변경 없음)

## 분리 정책

동일한 OSM 노선군 `kr-osm-line-8691899`만 대상으로 한다. 연구용 각 계통의 경로 및 정차역·방향·실제 way 목록·geometry를 다시 합성하거나 임의 연장하지 않는다. 선형을 이어 하나의 가짜 관통 계통으로 만들지 않고 각 source relation의 실제 정차 순서 그대로 실행한다.

운영 선택창에 **연구용 / 공식 운행 미승인** 표시를 유지하고, 연구용 플레이 기록은 정식 랭킹·일반 기록과 분리한다. 연구용 노선을 `releaseStatus=verified`로 올리지 않는다. 플레이 가능한 경로의 존재는 실제 시간표 운행이나 국가망 정식 출시 승인 근거가 아니다.

## 변경 범위

- `js/data-loader.js`: 한국 운영 목록의 1호선 5개 구간을 런타임에서만 숨기고, 인증된 preview index에서 허용된 수도권 1호선 23개 방향별 경로를 읽는다. 실패 시 기존 상태 유지.
- `js/app.js`: 23개 방향을 1호선 카드 및 통합 운행계통 선택에 묶고, preview API를 통한 차단 검증과 기록 분리를 유지한다.
- `tools/test-kr-line1-integration.cjs`: 1호선 필터·원본 보존·폐지 특급 차단·연구용 상태·미리보기 파일 존재를 검증한다.
- 다른 철도망: 일본·홍콩 노선 원본, 한국 2·3·5·6호선 원본 및 여객 계통의 데이터는 변경하지 않는다.

## 남은 과제

연천~광운대, 인천 방면 일반 열차, 광명 셔틀, 청량리~신창 급행과 같은 1호선 전체 운행을 이 23개 연구용 source relations가 완전히 대표한다고 주장하지 않는다. 기존 1호선 원본은 보존되며, 실제 분기와 시간표/정차 순서 검증 후 추가해야 한다. 연결되지 않은 연구용 노선의 geometry를 임의로 직선 결합하지 않는다. 브라우저 전 구간 플레이와 물리적 IME, 실제 운영 시간표 검증 결과는 별도 확인이 필요하다.
