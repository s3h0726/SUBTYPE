# 대만 잔여 철도 구현 결과 — 2026-11-01

기존 38개 카드를 유지하고 관광철도 7곳을 8개 카드로 추가했다. 쏸터우는 고속철도선과 고궁 남원선의 실제 분기를 별도 카드로 제공한다. 합계는 11개 운영사, 46개 카드, 운영사 단위 558개 역, 386개 운행 패턴 묶음, 505개 방향이다. 기존 운행 ID 347개와 역 ID를 유지했다.

| 관광철도 | 구현한 운행 |
|---|---|

봉봉열차는 [산림청의 2026-10-02 공지](https://www.forest.gov.tw/Index/news/0079364)에 따라 마오싱에 도달하지 않는다. 가상의 회차역을 만들지 않고 타이핑산 한 번만 입력한 뒤 왕복 선로를 달려 종료한다. 단일 정거장 자유주행은 비활성화하고 정해진 왕복 운행을 제공한다. 기존 순환선·다른 지역의 게임 진행은 변경하지 않았다.

관광철도 선형은 OSM 지도 API의 실제 철도 노드로 구성했다. 사용한 도형, 원본 압축 파일, 공식 안내 원문과 해시는 `data/tw/source/completion/`에 보관한다. 정거장은 해당 철도 선로에 연결하며 이름으로 다른 운영사의 좌표를 합치지 않는다. 시후 증기기관차의 임시 운행을 정기편으로 생성하지 않았다. 운행 요일·예약 조건은 선택 화면에 표시한다.

TRA 보류 221개 시각표 행의 139개 고유 방향을 모두 복구했다. 다른 정차역을 앞질러 지나가는 대체 경로와 무정차 분기점에서 되돌아가는 우회 경로를 제외해 과도한 모호성 판정을 수정했다. 마지막 107·111·131·165·167 열차는 공식 열차 조회 원문의 산선 표시를 별도 보존했다. 복구 원본과 생성 운행의 정차 순서는 집합 비교로 확인한다.

[고속철도 공식 홈페이지](https://www.thsrc.com.tw/ArticleContent/a3b630bb-1066-4352-a1ef-58c7b4e8ef7c)가 현재 제공하는 2026-02-02 시행 정기 시각표 PDF의 214행을 좌표 기반으로 추출했다. 기존 19개 정차 조합을 보존하고 타이베이–타이중 및 난강–타이중 조합 2개를 추가했다. 기존 조합 수정·삭제는 0개다. 지정 요일 운행을 매일 운행으로 표기하지 않는다.

타이난 지하화는 [철도국의 2026-10-17 개통 안내](https://www.rb.gov.tw/zh-TW/main/main_188/news/main_347/20261005_082504/)와 OSM 터널 선형 1570453085·1102288952·1102288954를 대조했다. 종관선 남부의 해당 구간과 타이난역 선로 위치를 갱신했다. 기존 선형과의 경계 오차는 약 0.07m·3.65m다. 린썬·난타이난 미개통역은 추가하지 않았다. 다른 구간의 전국 전수 GIS 인증을 주장하지 않는다.

검증 결과는 `reports/taiwan/completion/summary.json`, `engine.json`, `regressions.log`, `korea-regression.log` 및 `reports/taiwan/multilingual/browser.json`에 있다.
