# 경기도 공식 버스 대량 수집

`node tools/kr-provincial-gbis-fetch.cjs`로 공식 경기버스정보 지도에서 전체 검색
페이지를 순회한다. 노선번호 검색 0~9와 문자 노선 검색을 합치고 공식 routeId로
중복을 제거한다. 원본은 `data/kr/canonical/provincial-gbis-source/`에 gzip으로
보관한다. 재실행은 보관된 원본을 재사용한다. 최신 수집은 새 원본 디렉터리에서
실행하거나 필요한 날짜의 원본을 별도로 보관한 뒤 수행한다.

`node tools/kr-provincial-gbis-build.cjs`로 시군구별 canonical 배치를 생성한다.
공개 파일은 완성된 임시 파일을 atomic rename하여 교체한다.
`node tools/kr-provincial-gbis-test.cjs`로 전체 배치를 자동 검증한다.

출처는 경기도 경기버스정보 `schBusAPI.action`의 공개 지도 요청이다.

- `searchAllJson`: 노선 식별자·번호·관할 지역 전체 목록과 페이지 수.
- `searchRouteJson`: 운영사, 공식 분류, 시군구, 상·하행 독립 정차 목록, 회차점, 운행 시각.
- `searchMapLineJson`: 상·하행 독립 실제 도로 경로와 원본 정점 순서.

노선 데이터 이용 조건은 [공공데이터포털 경기도 버스노선 조회](https://www.data.go.kr/data/15080662/openapi.do)의
이용허락범위 제한 없음이다. [공식 노선형상정보 목록조회 설명](https://www.gbis.go.kr/gbis2014/publicService.action?cmd=mBusRouteLine)을
함께 참조한다. 경기도와 해당 데이터 출처를 보존한다. 지도 타일·로고·서비스
디자인·프로그램 코드는 데이터 배치에 포함하지 않는다.

좌표는 공식 지도에 제공되는 EPSG:3857을 EPSG:4326으로 변환한다. 도로 경로가
없을 때 정류장을 직선으로 잇지 않는다. 원본 도로 선분 위의 수직 투영점을
추가하여 정차 위치를 연결하되 원본 곡선 정점을 모두 유지한다. 정차지와 도로
사이 거리는 최대 150m, 인접 원본 도로점 간격은 최대 2km이다.

상·하행 원본 목록을 각각 처리하며 역순 배열을 만들지 않는다. 공식 `stationTp=6`
및 `(경유)`·`(미정차)`는 승하차 정류소가 아니므로 타자 대상에서 제외한다. 실제
도로 경로에는 그대로 남는다. 정류장 사이 거리는 `estimateTime.length`를 사용하고
제외한 경유 노드가 있으면 해당 구간 거리를 합산한다. 같은 이름의 정류장은
합치지 않고 원본 stationId로 구분한다. 라틴 문자가 포함된 상호·약어는 한국어
글자 이름으로 표시하며 원본 이름·식별자는 별도 보관한다.

현재 경기도 관할 `adminNm`을 가진 노선만 공개한다. 서울·인천 관할 목록은
공식 전체 수집 목록에 보존하지만 기존 서울 카탈로그와 중복 공개하지 않는다.
각 방향은 독립적으로 검증하며 한 방향이 실패해도 다른 적격 방향은 보존한다.
실패 노선·방향은 `provincial-gbis-report.json`에서 확인한다.

공개 배치는 시군구별 `provincial-gbis-시군구코드-batch.json`이다. 런타임은
canonical 컴파일러가 생성한 노선별 지연 로드 파일만 읽고 원본 전체를 시작 시
읽지 않는다. 실제 수량은 보고서와 테스트 결과에서 확인한다.
