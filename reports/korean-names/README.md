현재 저장소 원본 및 생성 데이터에서 추출한 자료입니다. 게임 코드와 운영 데이터는 수정하지 않습니다.

- 운영사: 171개
- 노선: 659개
- 역-노선 표기: 11361건
- 고유 역 표기: 9509건
- 생성 노선 상세정보 누락: 0개 ()

일본 철도 한글명은 나무위키 개별 문서/노선표 확인을 우선하며, 확인되지 않은 표기는 검토 필요 상태로 유지합니다. 편집표의 출처 검증·근거 URL 열은 원본 및 노선별 증거에서 추출합니다.

CSV는 UTF-8 BOM으로 저장되어 Excel에서 바로 열 수 있습니다. 동일 역의 한글명이 노선마다 다를 수 있어 stations-by-line.csv와 stations-unique.csv를 모두 제공합니다.

## 단일 편집 진입점

https://s3h0726.github.io/SUBTYPE/reports/korean-names/editor.html

이 페이지가 이제 유일한 철도 데이터 편집기입니다. 기존 `/editor/` 및 `/dev/rail-data-editor.html` 페이지는 삭제되었습니다. 게임 설정의 링크도 이 주소로 변경되었습니다.

- **한글명 · RGB · 라벨**: 국가별 운영사·노선·운행계통·역명을 편집하고, 라벨 및 색상을 변경합니다. 변경 사항은 GitHub Contents 쓰기 토큰을 통한 `data/editor-overrides.json` 저장 또는 CSV 내보내기로 적용할 수 있습니다. 브라우저 임시 편집은 기존 로직을 유지합니다.
- **노선 상세 · 역 순서 · 선형**: 이전 철도 데이터 편집기에서 지원했던 일본 workspace 노선 기본정보·역 순서·역번호·역명판 템플릿·로고 보기·지도 및 무결성 검증, JSON 가져오기/내보내기가 이 페이지로 통합되었습니다. 상세 편집 모드에서만 원본 노선 workspace 데이터를 불러옵니다.

**저장 방식 유의**: 노선 상세 구조 편집은 기존과 동일하게 JSON으로 내보내 `npm run editor:apply -- <파일 경로>`로 로컬 데이터에 반영하고, `npm run build:data` 및 회귀 검사를 거쳐 GitHub에 커밋해야 합니다. 한글명 편집의 GitHub 직접 저장 버튼으로 노선 구조까지 저장되지는 않습니다. 지도/선형 및 운영사 로고는 원래부터 확인용 미리보기였으며 직접 편집 기능을 추가했다고 주장하지 않습니다.
