## 구현·검증

신규 공항버스 45개 배치 레코드(신규 카드 40·기존 카드 병합 5), 85방향, 선형 좌표 99,200개를 공식 정차 ID·원본 도로 굴곡·실제 게임 경로로 검사했다. 철도 163계통의 원본 선분 475,146개와 임시승강장행 전체 원본 연결도 검사했다. 긴 공항 무정차 구간을 허용해도 원본 도로의 2km 초과 단절과 정류장의 150m 초과 이탈은 계속 거부한다.

새 필터 ‘공항버스·공항 연계’, 공항명 검색, 공식 영문 노선번호 대문자 및 계통 접미사 보존을 구현했다. 모든 새 카드·방향은 기존 선택·랭킹·결과·한국 이름 편집 구조를 사용한다. 편집표는 새 역·정류장 ID 전체를 중복 없이 제공하며 사용자 이름 덮어쓰기는 유지한다. 철도 원본은 고정 해시와 way ID로 공유하고, 빌드의 중복 좌표 참조도 직렬화 해시를 보존한다.

대표 브라우저 완주 5건: 의정부 차량기지행 16역, 포항 고속철도 8역, 서해선 홍성 순환 12역, 서울 공항버스 6103번 3정류장, 부산 공항리무진2 7정류장. 모두 정확도 100%·오타 0·정상 종점 및 게스트 저장을 확인했다. 자동 입력 검증이며 인간 타수 평가가 아니다. 서해선은 같은 역 재방문 후 종점에서 종료되는 것도 확인했다. 방향 선택은 의정부의 기존 탑석행에서 신규 임시승강장행으로 변경해 확인했다.

IME 자동 검사 10개, 도로 결합 검사 4개, 노선번호·이름 편집·KORAIL 역명판·공통 선형 무손실 검사가 통과했다. 실제 운영체제 한글 조합과 로그인한 Supabase 저장은 미검증이다. 과거 일본 공통 검사 2개 실패는 이번에 수리하거나 성공으로 재분류하지 않았다. 한국 카탈로그·Pages 워크플로 결과와 실제 배포 바이트는 별도 배포 증거 JSON에 기록한다.

서해선 원본 식별자 중복으로 최초 검사가 실패했으며 원본 행 위치와 전체 정차열을 구분하도록 수정한 뒤 통과했다. 원본 정차열을 단일 식별자 Map으로 덮어쓰지 않는다.
