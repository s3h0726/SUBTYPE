## 검증

자동 검사 12개 중 11개 통과, 1개 실패. 한국 공개 계통 전체 게임 경로 해석, 버스 원본 도로와 방향, 철도 원본 선형, 한강 항로, 한글 입력·IME, 홍콩 선택, 일본 목록 및 새 소부 쾌속선 보존, Supabase 연동 단위검사가 통과했다.

전체 데이터 검사는 기존 일본 역 마스터의 중복 식별자로 실패한다. 해당 입력인 data/stations/tokyo-stations.json과 검사 코드는 원격 main과 동일하다. 별도 기존 전국 철도 감사는 597개 중 557개 통과·40개 선형 대기를 보고한다. npm이 이 실행 환경에 없어 Node 검사기를 직접 실행했다.

브라우저 대표 완주: 지하철 까치산→도림천 4역, 교외선 대곡→의정부 6역, 서울 143번 56정류장, 한강버스 마곡→여의도 3선착장, 고속철도 용산→목포 6역. 지하철 반대 방향 전환도 확인했다. 자동 입력으로 정확도 100%, 게스트 기기 저장을 확인했다. 사용자 타수 평가나 전체 노선 브라우저 완주를 의미하지 않는다.

비서울 버스 완주와 로그인한 Supabase 서버 완주 저장은 미검증이다. 브라우저는 게스트였고 원격 스키마 읽기는 네트워크 오류로 판정 보류했다. 연동 단위검사는 통과했지만 실제 서버 업로드와 구분한다.

## 재생성

`node tools/build-kr-canonical.cjs --publish` 다음 `node tools/build-app-bundle.js`, `node tools/test-kr-canonical.cjs`를 실행한다.

`node tools/run-kr-rebuild-checks.cjs`는 검사 결과를 automated-checks.json에 저장한다. 교통수단별 수집기는 tools/kr-bus-*, tools/kr-rail-*, tools/kr-river-*에 있다. 원본·출처·실패 자료는 data/kr/canonical에 보존한다. 이전 한국 컴파일러와 연구용 목록 생성기는 새 카탈로그를 덮어쓰지 못한다.

계정·기록·Supabase SQL은 수정하지 않았다. 초기 GitHub 복구 지점은 backup/korea-before-rebuild-20261030이다. 기존 로컬 SUBTYPE 작업 폴더는 보존하고 최신 main의 일본·홍콩 변경 위에 재구축 커밋을 합쳤다.
