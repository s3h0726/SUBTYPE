# 홍콩 누락 운행계통 추가 — 2026-11-02

기존 103개 플레이 방향을 보존하고 검증 가능한 2개 방향을 추가했다. 고속철도는 추가하지 않았다. 최신 main `7edf6b43`을 fast-forward로 받아 한국·일본·대만 및 인증/저장 구현을 유지했다. 시작 상태는 태그 `backup/hk-before-missing-20261102`로 보존했다.

| 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| PLAYABLE 방향 | 103 | 105 |
| 전체 후보(고속철도 보관 후보 1 포함) | 104 | 106 |
| 공개 선택 카드 | 26 | 27 |
| 검수된 역·방향 정차 레코드 | 296 | 296 |
| 공유 track segment | 542 | 542 |

신규 물리 철로를 복제하지 않고 기존 원본 railway geometry를 재사용했다. 507P는 새로운 운행번호 카드이며 새로운 물리 철도 시스템으로 집계하지 않는다.

## 추가한 계통

- **경전철 507P 시우홍 → 튄문페리피어**: 19개 정차. 평일 07:42 특별편. [현재 MTR 시간표](https://www.mtr.com.hk/en/customer/services/schedule_index.html)와 [운영사 507P 전체 정차역 보도자료](https://www.mtr.com.hk/archive/corporate/en/press_release/PR-22-058-E.pdf)를 대조했다. 2022년 문서의 07:40 대신 현재 안내의 07:42를 적용했다. 방학 조건은 명시되지 않아 추정하지 않았다. 과거 Tuen Mun Swimming Pool은 현재 Hoi Wong Road, 동일 Stop ID 250으로 관리한다.
- **동철선 애드미럴티 → 목마차우, 마장 경유**: 14개 역. 경마일 등 운영사가 마장역을 개방하는 날의 지정 열차만 운행하며 상시 운행으로 표시하지 않는다. 기존 공식 지도·정차 근거를 유지하고 relation 4250434에서 누락된 사틴 정차 참조만 복구했다.

507P 보도자료의 원본 PDF URL은 현재 유지보수 HTML을 반환했다. 공식 검색 색인에 보존된 19개 정차역 표를 구조화해 저장했다. 이를 PDF를 직접 내려받은 것으로 기록하지 않았다. 현재 시간표 HTML 원본과 각각의 SHA256을 보존했다.

## 실제 선형과 환승

507P는 615의 시우홍→렁킹과 507의 렁킹→튄문페리피어를 사용한다. 접합점은 동일한 OSM 정차 node **1716515044**와 동일 좌표다. 틴킹 종착 회차 위치 대신 실제 통과 승강장 위치를 사용하며, 615P에만 포함되는 케이룬을 삽입하지 않았다. 구간마다 원래 relation 및 way 출처를 유지한다.

사틴 node **2185507487**은 relation4250434에 원래 포함된 railway way **208232725**의 정확한 꼭짓점이다. 새 좌표·way·연결선을 만들지 않았다. 원본 relation의 누락 기록은 그대로 남겼다.

틴킹의 기존 환승 검수에 507P를 추가했다. 기존 정차 레코드의 유일한 확장은 이 환승 목록 한 항목이며, 나머지 역 정보·선형·검증 identity는 이전 103개와 비교한다.

실제 TAB 검사에서 최신 main이 환승역 입력을 건너뛰는 문제를 재현했다. 홍콩에서 동일 환승 node의 노선만 바뀌면 새 승강장의 현재역부터 입력하도록 수정했다. 다른 역으로의 주행 및 한국·일본의 기존 처리는 유지한다. 틴킹 **507P→615→507P→615**의 TAB 전환 3회와 환승 후 12개 정차의 종착 진행을 브라우저에서 확인했다.

## 검증

- 105개 전 방향을 실제 Game/TypingController의 AUTO·SPACE로 실행: **210회 완주**, 중복 입력·정차 순서·종착 종료 검사. DOM fixture의 지도 paint/애니메이션은 모의 처리이며 브라우저 성능 측정과 구분한다.
- 신규 2방향의 실제 브라우저 전 구간 완주: 각각 19개/14개 정차, 정확도100%, 오타0. 507P AUTO, 동철선 SPACE.
- 최종 자동 검사 및 재빌드 해시: `validation.json`과 개별 실행 로그 참조. 재빌드 전후 모든 홍콩 생성물 및 앱 번들 일치 검사 포함.
- 이전 검사에서 수량61→63과 최신 main의 종착 안내 문자열 변화가 확인됐다. 수량은 신규2개에 맞게 정확히 갱신하고, 종착 상태·입력 잠금·외국 노선 자동 진입 금지 검사는 그대로 유지했다.
- 실제 TAB 첫 타이핑역 실패는 코드 수정 전 재현 사례로 남기고 수정 후 결과와 구분한다. `browser-failures.json`, `browser-transfers.json` 참조.

모바일390×844 재검사, 실제 Windows IME, 물리 모바일 키보드, Supabase 실계정 왕복 저장은 이번 변경에서 **NOT_TESTED**다. 기존 AUTO 성능 FAIL은 유지한다. 신규 노선의 소수 표본으로 기존 p95 문제가 해결됐다고 주장하지 않는다.

## 보류

APM T2/RR, 경전철506P·610P·720은 전 정차·방향별 승강장·실제 연결 근거가 충분하지 않아 추가하지 않았다. 피크트램 현재 요청 정차 규칙의 미확정 상태와 기존 명시적 모의운행을 유지한다. 홍콩 전체 철도 완성으로 선언하지 않는다. 고속철도는 명시적 범위 밖이다.
