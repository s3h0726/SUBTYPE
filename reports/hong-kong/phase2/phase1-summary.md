# 홍콩 철도 구현 및 검증 결과

검증일: 2026-10-20. 공식·OSM 원본 수집 기준일: 2026-10-18.
전체 상태: **INCOMPLETE**. 180개 요구사항 중 PASS 36개, INCOMPLETE 143개, 선택 범위 밖 1개. PASS는 각 항목에 기록한 구현 범위에 한정한다.

## 구현된 기능

- 홍콩 선택, 교통수단별 분류, 서비스 검색과 미검증 서비스 목록, 지연 로딩.
- 공식 정차 패턴과 OSM 실제 선형을 별도로 보관하는 오프라인 재생성 파이프라인. 25개 노선 레코드, 55개 서비스 패턴, 277개 역·방향별 정류장 레코드, 486개 실제 선형 구간. 277은 고유 실물 역 총수가 아니다.
- 디즈니랜드 리조트 라인 DT/UT 2개 방향 플레이. 방향별 원본 선형을 독립적으로 사용한다. 이름·정차·선형 검증을 통과하지 못한 서비스는 플레이를 차단한다.
- 번체중문·영문·한국어 표시, 한국어 따라쓰기·암기, AUTO·SPACE 이동, 기록 저장. 암기 모드의 한국어 지도·힌트 누출 수정.
- 검증된 방향 구간만 연결하는 홍콩 CUSTOM 생성·저장·재실행. 임의 직선 연결과 미검증 환승은 허용하지 않는다.
- 390px 모바일 입력판 잘림·상태 표시줄 위치 수정, 라이트·다크 테마 확인.

## 남아 있는 자료와 검증

- 한국어 이름 270개 미입력, 275개 검토 대기. 검토 완료 이름은 써니베이와 디즈니랜드 리조트 2개뿐이다.
- 선형 50/55 검증, 5개 미검증. 정차 패턴 30개 미검증. 좌표 누락 0개는 전체 노선 검증 완료를 뜻하지 않는다.
- 공식 경전철 추가 표기 506P·507P·720·610P는 기존 12개 목록 외 검토 대상이다.
- 피크트램·고속철·트램·공항철도·나머지 MTR의 플레이 승인, 한국어 명칭, 운영 조건, 환승, 공식 로고·색상·이용 조건은 미완료다.
- Peak FAQ와 관광청 한국어 PDF 원문 접근 실패를 기록했다. 없는 자료를 확인 완료로 처리하지 않았다.
- Supabase 공개 설정이 없어 로그인·클라우드 동기화는 검증하지 못했다.

## 검증

CUSTOM ID·한국어 답안 누출 회귀 검사를 포함한 통합 회귀 테스트 78개(홍콩 14개)를 모두 통과했다. 타이핑 18개, IME 10개, 데이터·서비스·경로 해석·한국 데이터·단일 원본 검증 통과. 기존 UI 감사는 4개 소스 정규식 검사에서 실패하며 최신 원격 main과 동일하다. 따라서 전체 검증을 모두 통과했다고 표기하지 않는다. 상세 결과는 validation.json, validation.txt, legacy-ui-baseline.json 참조.

브라우저에서 DT 일반 AUTO 완주, UT 암기 SPACE 완주, CUSTOM 저장·재실행, JP/KR 목록 복귀를 확인했다. 2026-10-20에는 390×844 라이트·다크 화면, 긴 역명 입력칸, 암기 AUTO 완주(3.09km, 정확도 100%, 오류 0)를 재확인했다. 해당 로컬 세션 콘솔 오류는 0개다. 다른 미검증 서비스와 클라우드 동작까지 포함한 수치가 아니다.
