## 브라우저

이 작업에서 서로 다른 17방향의 완주를 확인했다. 신규 11방향 모두 완주 기록이 있다. 최신 원격 병합 뒤 피크 상행 AUTO/하행 SPACE·공항 APM·751P 오전·췬완선 단축·홍콩섬선·705/706·트램을 대표 재실행했다. 705/706은 최초 출발역과 마지막 재방문을 별개로 입력했다. 암기 모드 전체·모든 화면·모든 92개 방향의 브라우저 재완주는 이번에 실행하지 않았다.

애드미럴티 홍콩섬선→췬완선 TAB을 왕복 포함 3회 전환하고 새 환승역 입력부터 센트럴 종착까지 검증했다. 실제 선로별 정차 좌표는 자동 검사와 연결했다. 다른 기존 환승 쌍 전체는 이번 브라우저에서 재실행하지 않았다. APM에서 TAB이 도시철도로 전환되지 않음을 별도로 확인했다.

390×844 밝은 모드 APM, 모바일 피크 SPACE, 데스크톱 어두운 모드와 한국어 우선 역명판을 확인했다. 가로 넘침 0px, APM 전용 차량 표시를 확인했다. screenshot은 실제 UI 관측이다. CUSTOM은 실제 저장 소스를 새 VM으로 재생성해 복구 검사했으며, 이번 브라우저에서 편집기 저장·새로고침 왕복은 재실행하지 않았다.

빠른 fill 호틴행 1회에서 종착까지 진행했지만 정확도 99.3%/오타 1건이 기록됐다. 실패를 browser-failures.json에 보존했다. 순차 입력 재실행은 100% 완주했고 원인은 미확정이다. 그 외 초기 UI 선택기·계측·병합 문법 오류도 발견 후 수정했으며 초기 테스트 결과는 merge-first-test-attempts.json 등에 보존한다.

## 다른 국가·계정

최신 원격에 다른 작업자의 한국 재구축이 들어왔다. 이전 0개 상태를 다시 덮어쓰지 않고 현재 471개 공개 계통/1087개 경로 해석/geometry fallback 0개를 보존했다. 한국 canonical 및 publication policy 검사는 PASS다. 최초 0개 상태를 확인한 브라우저 기록은 과거 시점 증거로 남겼으며 최종 상태를 0개라고 보고하지 않는다.

일본 NEX 8개 게임 경로, 쇼난신주쿠 및 조반 계통 검사는 PASS다. 니시큐슈 신칸센 5개 역 브라우저 완주도 기록했으나 최신 원격 통합 전 표본이다. 일본·한국·대만 원본과 현재 인증·저장·랭킹 코드에 홍콩 변경 차이는 없다. 대만 최신 10개 회귀 검사는 10 PASS다.

Supabase 테스트는 실제 현행 FEATURE_FLAGS를 fixture에 로드하고 계정 간 로컬 저장 분리·랭킹 eligibility·SQL 정책/재시도 계약을 검사했다. PASS는 fixture/정적 범위이며 실제 서버 로그인·계정 저장·로그아웃·복원은 NOT_TESTED다. 실제 Windows IME와 물리 모바일 키보드도 NOT_TESTED다.

## 구형 전체 검사군의 실패도 보존

기존 HK 67개 검사군의 최종 실행은 **60 PASS / 7 FAIL**이다(historical-final.txt). 실패를 삭제하거나 모두 PASS로 보고하지 않는다.

- 고정 총수 92 대 현재 103, 일반 동철선 4 대 마장 포함 7, 이전 범위 61 대 69: 세 가지 과거 snapshot 집계 기대값.
- FEATURE_FLAGS 및 koreanRouteDisplayText: 두 구형 VM fixture 의존성 누락.
- 240ms 애니메이션 완료 기대와 기존 UI 동작 도구: 최신 main 엔진/지연 기준 관련 두 실패. 현재 motion 계약 13개와 AUTO 실측 FAIL을 별도로 기록했다.

시작 main의 일본 선택기 정적 문자열 검사와 삭제된 조반 분할 파일을 요구하는 검사 2건도 baseline-comparison.json에 동일 실패를 재현해 남겼다. 최신 관련 NEX/쇼난/조반 검사 PASS가 이 실패를 소급해서 지우지는 않는다. 전체 프로젝트가 무결점 PASS라는 결론을 내리지 않는다.
