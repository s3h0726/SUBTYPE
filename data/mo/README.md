# SUBTYPE Macau LRT (MO)

2026-11-14 기준, 영업 중인 마카오 경전철 3개 노선만 구현합니다.

| 노선 | 역 수 | 정차 순서 |
|---|---:|---|
| 타이파선 | 13 | 바라 → 해양 → 자키클럽 → 경기장 → 파이꼭 → 코타이웨스트 → 로터스 → 유니언병원 → 동아시안게임 → 코타이이스트 → 마카오과학기술대학교 → 공항 → 타이파페리터미널 |
| 섹파이완선 | 2 | 유니언병원 → 섹파이완 |
| 헝친선 | 2 | 로터스 → 헝친 |

- 3개 노선, 6개 양방향 플레이, 중복 환승역 2개를 제외한 15개 실제 역 ID.
- 환승역 ID는 로터스(타이파/헝친), 유니언병원(타이파/섹파이완)에서 공통 사용.
- 정차순서와 영업 상태: https://www.mlm.com.mo/en/route.html
- 한국어 역명: https://www.namu.moe/w/마카오%20경전철%20타이파선
- 지도 선형: https://www.citylines.co/api/macau/raw_source/sections (공개 실선로 형상에서 주요 꼭짓점 추출, 역 좌표는 실선로 근사 스냅 좌표. 정확한 측량 데이터는 아님.)
- 공식 운영사 타이파선의 역 목록 중 로터스 위치를 Hengqin이라고 표기한 부분은 공식 노선도/헝친선 상세 설명에 따라 Lotus로 대조 반영.
- 공식 동선(East Line)은 공사 중이므로 게임 운행 노선에 포함하지 않습니다. 실제 시각표별 열차 출발 시각은 이번 데이터에서 주장하지 않습니다.
