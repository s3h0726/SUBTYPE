# Hankyu Kobe Kosoku Line

- Operator: Hankyu Railway
- Japanese: 阪急神戸高速線
- Korean: 한큐 고베 고속선
- Operational section: Kobe-Sannomiya to Shinkaichi
- Stations: 4 (Kobe-Sannomiya, Hanakuma, Kosoku-Kobe, Shinkaichi)
- Geometry: reused from the shared Kobe Kosoku Tozai line where available

This is Hankyu's operating section over shared Kobe Kosoku infrastructure, represented separately from the physical infrastructure line.
