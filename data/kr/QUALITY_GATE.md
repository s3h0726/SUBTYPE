# 한국 노선 품질 게이트 (2026-10-09)

현재 한국 교통 데이터는 **검증 전 임시 수록본**이며 메인 사이트로 배포하지 않는다.

## 검증
```bash
node tools/audit-kr-national-catalog.js
node tools/validate-korea-data.js
npm run build:korea
```

한국 노선은 `js/korea-index-data.js`에 인덱스가, `data/kr/generated/routes/`에 상세가 있다. 인덱스가 권위 있는 최신 운영기관 분류를 가진 경우 상세 데이터를 읽은 뒤 메타데이터를 적용한다. 이후에는 원본 `data/kr`에 통합해 재생성해야 한다.

## 출시 전 필수 보완
- 코레일 공동운영 노선의 실제 회사별 관리 구간 확인
- 수도권 최신 개통·연장역 및 분기/급행 운행계통 확인
- 동해선·대경선·GTX-A 등 운영 현황 재검증
- 한강버스 실제 선착장별 정차·회항과 변경 가능한 운항편 분리
- 각 역·선착장의 좌표 및 실제 선형 검증
- 동일 지명의 환승 후보를 공식 자료로 확인하여 별도 확정
- `js/app.bundle.js`를 소스에서 재빌드하고 브라우저에서 한국 탭 전환·역 타이핑 테스트

일본 관련 기존 빌드/데이터는 보존한다.
