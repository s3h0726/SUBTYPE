# 대한민국 도시·광역철도 전면 재구축 (2026-10-09)

기존 한국 교통의 샘플 9개 노선과 버스·한강버스·KTX 데이터는 모두 이 작업 브랜치에서 제거한다. 일본 데이터는 절대로 변경하지 않는다.

## 적용 범위
한국은 별도 국가(kr)로 유지한다. 한국 노선은 실제 **영업 중인 도시철도·광역철도**만 채택한다. 고속철도, 시내버스, 한강버스는 이번 도시·광역철도 카탈로그에 포함하지 않는다. 미개통 노선을 노출하지 않는다.

## 지역 구분
- 수도권: 서울 1~9호선, 코레일 수도권 전철 각 노선, 공항철도, 신분당선, 우이신설선, 신림선, 김포골드라인, 용인경전철, 의정부경전철, 인천 1·2호선, GTX 등 개통 노선
- 부산·울산: 부산 1~4호선, 부산김해경전철, 동해선 등
- 대구·경북: 대구 1~3호선, 대경선 등
- 대전: 현재 개통된 도시철도
- 광주: 현재 개통된 도시철도

## 데이터 원칙
1. 운영기관·노선·역·정차 순서·행선지/운행계통·노선 선형과 환승을 각각 검증한다.
2. 정차역 목록이 정확하지 않은 노선은 플레이 가능 목록에 공개하지 않는다.
3. 구간별 분기·급행·직통은 별도 운행계통으로 분리한다.
4. 선형 자료가 없는 구간에 가짜 직선을 그리지 않는다.
5. 원본은 data/kr 아래, 자동 생성물은 빌드로만 만든다.
6. 한국 선택 UI는 전국 개통 노선의 데이터 구축·검증이 완료되기 전까지 비활성화 상태로 둔다.
7. 기존 한국 노선으로 저장된 이용자 기록은 별도 마이그레이션 전까지 새 노선으로 매핑하지 않는다.
