요청 URL

http://apis.data.go.kr/6410000/busrouteservice/v2/getBusRouteInfoItemv2

요청 Parameter
파라미터 표. 노선정보 항목조회 파라미터 변수명, 타입, 설명에 대한 안내입니다.
변수명 타입 설명
serviceKey 문자열 인증키(공공데이터포털 발급)
routeId 문자열 노선ID
format 문자열 응답 포맷(json/xml)
샘플 URL

routeId 가 200000085 인 노선의 노선정보를 검색할 경우:
- https://apis.data.go.kr/6410000/busrouteservice/v2/getBusRouteInfoItemv2?format=json&serviceKey=공공데이터포털에서 발급받은 서비스키&routeId=200000085

공통 응답 메시지 표. 공통 응답 메시지 변수명, 타입, 설명에 대한 안내입니다.
