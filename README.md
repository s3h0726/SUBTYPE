# SUBTYPE

**역 이름을 타이핑하고, 세계의 철도와 대중교통 노선을 달려보세요.**

SUBTYPE은 실제 교통 노선과 정차역을 바탕으로 만든 **한국어 대중교통 타이핑 게임**입니다. 국가·지역을 고르고, 운영사와 노선, 운행계통 및 방향을 선택한 뒤 역명을 입력하면 지도 위의 차량이 다음 역으로 이동합니다.

[**▶ 웹에서 플레이하기**](https://s3h0726.github.io/SUBTYPE/) · [변경 이력](CHANGELOG.md) · [문제 제보 및 제안](https://github.com/s3h0726/SUBTYPE/issues)

> **현재 버전: v0.17.0 (개발 중)**  
> 설치 없이 웹 브라우저에서 플레이할 수 있습니다. 노선·역명·운행계통 데이터는 계속 확장 및 검증하고 있으며, 모든 국가의 교통망을 완전하게 재현한 것은 아닙니다.

## 어떤 게임인가요?

일반적인 단어 타이핑 대신 **실제 역명과 정류장명**을 입력합니다.

1. **국가·지역 선택** — 세계 지도 또는 목록에서 플레이할 곳을 고릅니다.
2. **노선 선택** — 교통수단, 운영사, 노선을 찾습니다.
3. **운행 설정** — 제공되는 운행계통, 방향, 출발역과 도착역을 선택합니다.
4. **타이핑** — 역명판을 보며 한국어 역명을 입력합니다. 입력 진행에 맞춰 지도상의 차량이 이동합니다.
5. **기록 확인** — 완주 시간, 정확도, 분당 타수, 오타, 콤보와 운행 경로를 확인합니다.

**[지금 SUBTYPE 시작하기](https://s3h0726.github.io/SUBTYPE/)**

## 지원 국가·지역

현재 선택 화면에는 **7개 국가·지역 분류**가 있으며, 홍콩과 마카오는 하나의 분류에서 각각 선택하므로 실제 플레이 대상은 **8개 국가·지역**입니다.

| 국가·지역 | 주요 교통 콘텐츠 |
| --- | --- |
| 🇰🇷 **대한민국** | 도시·광역·일반·고속철도, 버스, 한강버스 |
| 🇯🇵 **일본** | JR, 지하철, 사철, 신칸센, 특급 및 다양한 운행계통 |
| 🇭🇰 **홍콩** | 도시철도, 트램 등 |
| 🇲🇴 **마카오** | 경전철 타이파선·섹파이완선·헝친선 |
| 🇹🇼 **대만** | 도시철도, 고속철도 등 |
| 🇹🇭 **태국** | 국철, 도시철도 등 |
| 🇬🇧 **영국** | 런던 교통망, 지역 철도, 내셔널 레일의 일부 노선 |
| 🇫🇷 **프랑스** | 지하철, TGV, Intercités, 일부 지역철도 노선 |

**홍콩·마카오** 카드를 선택하면 홍콩과 마카오를 별도로 고를 수 있습니다. 지원 범위는 국가마다 다르며, 등록된 노선과 실제 운행 가능한 방향 수는 계속 변경될 수 있습니다. 일부 노선은 자료와 선형 검증이 완료되기 전까지 플레이 대상에서 제외됩니다.

## 게임 기능

### 실제 운행계통을 따라가는 플레이

- 하나의 노선에서도 각역정차·급행·특급·직통 등 **등록된 운행계통**을 구분합니다.
- 계통에 따라 정차역과 운행 구간이 달라질 수 있으며, 가능한 경우 선택한 계통의 정차역만 표시합니다.
- 순방향·역방향, 출발역·행선지를 선택할 수 있습니다.
- 실제 근거가 없는 운행 패턴을 임의로 추가하지 않는 것을 원칙으로 합니다.

### 타이핑 모드

| 구분 | 설명 |
| --- | --- |
| **따라쓰기** | 표시된 한국어 역명을 보고 입력 |
| **암기** | 한국어 정답을 가리고 다른 언어의 역명 표기를 참고해 입력 |
| **노선 완주** | 선택한 운행 구간의 정차역을 순서대로 진행 |
| **랜덤 60초** | 제한 시간 동안 역명을 입력 |
| **순서 맞히기** | 역 순서를 기억하며 다음 역을 입력 |
| **무한 모드** | 정해진 종료 지점 없이 계속 타이핑 |

정답 입력 후에는 **AUTO**(자동 진행)와 **SPACE**(확인 후 스페이스바로 진행) 중 선택할 수 있습니다. 게임 중에는 일시정지와 테마 전환도 가능합니다. 한국어 입력기는 조합 중인 글자와 완성된 글자를 구분하여 처리합니다.

### 지도·역명판·자유주행

- **지도 기반 이동**: Leaflet과 OpenStreetMap을 활용하여 역 위치와 노선 선형, 차량 진행을 표시합니다.
- **운영사별 역명판**: 실제 역명판의 구성과 색상 체계를 참고한 디자인을 적용하고 있습니다. 적용 범위와 재현 완성도는 운영사별로 다릅니다.
- **자유주행**: 지원되는 철도망에서 인접역과 검증된 환승 연결을 선택하며 이동할 수 있습니다.
- **한국어 중심 표기**: 타이핑 정답은 한국어를 기준으로 하되, 원어 역명과 현지 표기를 보조 정보로 활용합니다.
- **한국어 명칭 보정**: 국가별 한글명 편집 도구를 통해 역명과 노선명 표기를 수정할 수 있습니다.

지도 선형과 운행 정보는 출처 및 국가별 데이터 구축 상태에 따라 정확도에 차이가 있을 수 있습니다.

### 기록·커스텀 노선

- 완주 시간, **CPM**, **WPM**, 정확도, 오타 및 최대 콤보 확인
- 최근 플레이 및 개인 기록 관리
- 선택한 노선의 운행 구간과 지도 경로 확인
- 나만의 커스텀 노선 작성·저장 및 JSON 가져오기/내보내기
- 계정 로그인과 클라우드 기록·랭킹 기능(연동 상태와 인증 환경에 따라 이용 가능 여부가 달라질 수 있음)

## 버전 자동 관리

`main` 브랜치에 코드·교통 데이터·화면·개발 스크립트가 반영되면 GitHub Actions의 **Auto-release SUBTYPE version**이 새 버전을 발행합니다. 문서만 수정한 경우에는 버전을 올리지 않습니다.

- **PATCH** (`v0.9.1 → v0.9.2`): 일반 코드 변경, 수정, UI 개선.
- **MINOR** (`v0.9.2 → v0.10.0`): 커밋 제목을 `feat:` 또는 `feat(scope):`로 작성한 기능 추가.
- **MAJOR**: 1.0.0 이상은 필요할 때 Actions에서 수동으로 지정합니다.
- **수동 관리**: `package.json`을 직접 올린 커밋은 한 번 더 증가시키지 않고, 표시·문서·태그만 맞춥니다.

릴리스 작업은 `package.json`, 웹 화면, README, CHANGELOG를 동기화하고 **`vX.Y.Z` 태그**를 생성합니다. 검증을 통과한 후 GitHub Pages 배포 작업을 시작합니다. 자동 릴리스 커밋이 다시 릴리스를 실행하지 않도록 구성했습니다. 수동 실행은 GitHub의 **Actions → Auto-release SUBTYPE version → Run workflow**에서 PATCH/MINOR/MAJOR를 선택하면 됩니다.

## 개발 및 검증

**주요 기술**: HTML, CSS, JavaScript, Node.js 기반 빌드·검증 스크립트, Leaflet, OpenStreetMap. 계정 및 온라인 기록에는 Supabase 연동 기능이 사용됩니다.

Node.js 환경에서 필요한 개발 의존성을 설치한 다음 목적에 맞는 명령을 실행합니다.

```bash
npm install

# 앱 번들 및 버전 표기 동기화
npm run build:app
npm run test:version

# 노선 선택·역명판 관련 검사
npm run test:route-selection
npm run test:all-nameplates

# 데이터 구축·검증
npm run validate:data
npm run build:data
npm run test:single-source

# 저장소의 기본 종합 검사
npm test
```

일부 국가별 검증 작업은 별도 데이터 스냅샷, Python, 브라우저 자동화 도구 또는 추가 환경 설정을 요구합니다. 전체 명령과 정확한 실행 전제는 [package.json](package.json) 및 국가별 기술 문서를 참고하세요.

### 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `index.html` | 웹 게임 진입점과 주요 화면 |
| `css/`, `js/` | UI, 입력 처리, 지도, 운행 및 자유주행 로직 |
| `data/` | 국가·운영사·노선·역·운행 데이터와 출처 정보 |
| `tools/` | 데이터 변환, 번들 생성, 무결성 검사 및 테스트 |
| `editor/` | 철도 데이터 편집 도구 |
| `docs/`, `reports/` | 국가별 확장 문서, 진행 상황, 검증 결과 |
| `supabase/` | 계정 및 랭킹 관련 SQL·설정 문서 |

**원본 데이터와 생성 파일을 구분해 주세요.** 운영사·노선·역 정보는 원칙적으로 `data/` 아래의 원본을 수정하고, `data/generated/` 및 생성된 JS 번들은 빌드 명령으로 갱신합니다. 자세한 절차는 [철도 데이터 편집 가이드](DATA_EDITING_GUIDE.md)에서 확인할 수 있습니다.

## 데이터 원칙과 알려진 한계

SUBTYPE은 교통망의 양적 확장뿐 아니라 **역 순서, 정차 패턴, 환승 연결, 한국어 명칭 및 실제 선형의 검증 가능성**을 중요하게 생각합니다.

- 공개된 운영사 자료, 시간표, 교통 오픈데이터, 지도 데이터를 노선별로 대조합니다.
- 물리적인 선로와 여객 운행계통을 구분하며, 같은 선로를 사용하는 여러 운행을 별도로 다룰 수 있습니다.
- 한국어 역명 중 일부는 편집 표기 또는 자동 전사 결과이므로 추가 교정이 필요할 수 있습니다.
- 출처가 부족한 노선·정차역·선형은 추측으로 완성된 것처럼 표시하지 않습니다.
- **현재 시간표, 실시간 운행 상황, 운임 및 길찾기를 보증하는 교통 안내 서비스가 아닙니다.** 실제 이동에는 해당 교통기관의 최신 공식 안내를 확인하세요.
